## 具体实现决策

1. 首页保持综合编辑排序，非编辑频道按最新；提供明确排序文案。历史返回保护位置，主动刷新不冻结前缀。
2. 实时 API 继续依赖共享 DB 限流，DB 故障时复用已有安全快照而不启动新抓取。前端将错误提示与源失败数量分开，显示缓存年龄。
3. DB 页面改用动态请求，避免构建冻结故障文案；发布脚本另行检查 DB、迁移与关键模块，就绪失败直接停止。
4. 本机阅读条目以原文 URL 为统一身份，可带 Article ID；保存标题、来源、URL、时间等最小快照。旧数字标记兼容迁移，不丢用户记录。
5. 查询采用有界分页或显示上限，排序增加稳定 ID 次键；搜索已提交状态以 URL 为准。
6. Digest 提交在数据库事务内验证 lease 所有权，网络调用期间续租。恢复探测区分人工停用和自动熔断。
7. 今日简报保留 UTC 编辑日并明确显示，北京时间 08:00 换日；不只修改日期展示而改变语料含义。
8. 同一问题的 Ask 缓存关联当前语料内容指纹；客户端验证 sources/delta/done 协议完整性。
9. 语言偏好使用可供服务器读取的轻量 cookie（仅语言，不是用户系统），本机旧偏好兼容；正文按实际语言标记。
